## Download

[Download the HTML file](https://github.com/confoundedkyle/interview-record/raw/refs/heads/main/interview-record.html)

## Data handling

This is a blank form template. It does not include candidate records or a preconfigured Google Sheets endpoint. Drafts and an optional endpoint are stored in the visitor's browser. Records are sent to a Google Sheet only if the visitor connects their own Apps Script web app URL. Use a candidate reference instead of a candidate's name, as the form recommends.
